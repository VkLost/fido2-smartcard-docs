# FIDO2 Smartcard with GPG

Use a hardware-backed OpenPGP smartcard with FIDO2-compatible devices on Linux.

## Overview
This project documents the use of a  FIDO2 device as an OpenPGP smartcard on Linux systems.

## What this covers
- Generating GPG keys directly on the hardware token
- Fixing slot and key cache issues
- Signing and encrypting with smartcard
- Troubleshooting and recovery procedures

## Project structure
- setup/ → installation and configuration
- troubleshooting/ → problems and solutions
- images/ → screenshots and logs

## Requirements
- GnuPG installed
- pcscd running
- FIDO2 device connected
